이 앱은 다운로드도 실행도 하지 않습니다. 아래 모든 수치는 각 엔진의 공개된 크기 표와 선택한 프로필(가상 VRAM · DRAM · 컨텍스트)로 계산한 예상값입니다. 실제 설치·측정 결과와 다를 수 있으며, 판단의 참고만으로 사용하세요. 아무 모델도 이 컴퓨터에 받아지지 않습니다. 이 화면의 모든 결과는 예상치일 뿐이며, 실제 작동을 보장하지 않습니다.

1 이 컴퓨터의 실제 스펙 확인

OS · GPU · RAM을 확인합니다. 브라우저는 GPU 이름과 코어 개수만 정확히 알 수 있고, VRAM·RAM 총량은 제한 때문에 모자라게 보고될 수 있어 직접 확인해 고칠 수 있게 두었습니다 (Windows 작업 관리자 참고). 다른 스펙으로 실험하려면 가상 스펙 지정을 쓰세요.

4 예상 측정값 — 3단 계층

이 엔진·모델의 설계된 메모리 계층입니다: VRAM = 활성 전문가 + 콘텍스트 · DRAM = 비활성 전문가(항상 대기) · SSD = N-gram 임베딩·테이블 (설계대로 놓는 곳, 누수 아님). 어느 한 계층이 자기 자리를 넘칠 때만 누수(PCIe 재읽기 · 파일 재읽기)로 판단합니다. 통합 RAM 하드웨어에서는 VRAM/DRAM 행이 통합 RAM 행으로 표시되고, 넘칠 때는 바로 파일 재읽기가 됩니다.

VRAM(활성+밀집)콘텍스트 캐시RAM(비활성 대기)SSD(N-gram 설계)누수(초과분)
